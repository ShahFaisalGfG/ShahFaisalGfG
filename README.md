# Shah Faisal

AI developer at [Meissasoft](https://github.com/meissasoft), based in Lahore, Pakistan. I build AI automation and the full stack it runs on.

My day-to-day work is AI automation with LangChain on Anthropic and OpenAI models, and everything it runs on: system design, FastAPI backends on PostgreSQL, Next.js frontends, and AWS deployments. In my own time I build free, open-source tools under the **gfgRoyal** name: an offline AI studio, an Agent Skill for coding agents, and apps for Windows and the web. They run on your own machine and collect no data.

## Featured work

**[TruAris](https://www.truaris.com)**, an autonomous revenue intelligence platform that finds prospects, writes to them in their own language from a business's own mailboxes, and turns replies into qualified pipeline. I started it from scratch and own its backend end to end: multi-tenant Postgres with row-level security, Celery workers for prospecting and qualification, multilingual outreach through Amazon SES, AI agents on a LangChain layer over Anthropic and OpenAI, and deployment to AWS ECS through GitHub Actions. I also work on its Next.js web app and platform-admin panel. The code is private.
